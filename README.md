# Restaurant Management System

A beginner-friendly backend project for managing a restaurant using Node.js, Express.js and MySQL.

## Technologies Used

- Node.js
- Express.js
- MySQL
- mysql2
- Postman
- dotenv

## Project Features

### 1. Menu Management
- View menu items
- Add menu items
- Update menu items
- Delete menu items

### 2. Customer Management
- View customers
- Add customers
- Update customers
- Delete customers

### 3. Order Management
- Place orders
- View orders
- Update order status
- Delete orders
- Automatically calculate order total

### 4. Inventory Management
- Add inventory items
- View inventory
- Update inventory
- Delete inventory
- Automatically reduce inventory when an order is placed

### 5. Table Management
- Add restaurant tables
- View tables
- Reserve tables
- Make tables available again
